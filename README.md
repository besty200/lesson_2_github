# Напоминания для Windows 11

Небольшое настольное приложение на Python с интерфейсом Tkinter. Напоминания
хранятся в `reminders.db` рядом с файлами приложения; база и таблица создаются
автоматически при запуске. Для работы нужны Python 3.10 или новее. Внешние
пакеты не требуются. В Windows приложение использует Win10 Toast, если доступен
пакет `win10toast` и системные уведомления срабатывают; иначе показывает popup
окно Tkinter.

## Структура

- `database.py` — создание и миграция SQLite-базы, напоминания, статусы и выборка
  наступивших задач.
- `notifications.py` — фоновая проверка каждую секунду, системные уведомления
  Windows и popup-окна.
- `gui.py` — интерфейс Tkinter, создание и управление напоминаниями.
- `main.py` — точка входа приложения.

## Запуск

```powershell
python main.py
```

Запускайте приложение в интерактивном графическом сеансе Windows. При запуске
в удалённой Linux-среде или контейнере без графического дисплея интерфейс
Tkinter недоступен; приложение выведет объяснение вместо длинной трассировки.
Для такой среды нужен настроенный графический дисплей.

Тесты можно запустить командой `python -m unittest`.

Создавайте напоминания, задавая дату в формате `ГГГГ-ММ-ДД ЧЧ:ММ`.
Список можно отфильтровать по статусу. Выбранное напоминание можно удалить,
отметить выполненным или отменить. Просроченные напоминания автоматически
получают статус «Просрочено».

Планировщик работает в отдельном фоновом потоке, поэтому напоминания
срабатывают и при свёрнутом главном окне. При наступлении срока появляется
поверх остальных окон popup-окно. Закрытое уведомление не помечает напоминание
выполненным; кнопка «Готово» меняет его статус. Напоминания, наступившие пока
приложение было закрыто, также показываются при следующем запуске.
